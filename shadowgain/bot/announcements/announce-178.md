# Crafting has a real path now

The crafting and tinkering skills have never been worth training here. Measured across everyone above level 50: **not a single character had gained one rank of Cooking.** Alchemy averaged 3, Lockpick 3, Fletching 9. That is not players ignoring them — it is the numbers being impossible.

**Crafting turn-ins now pay in ranks, not experience.**

The old Crafting Experience Tasks are still there and still work the same way: craft something, hand it to the collector, get paid. What changed is what "paid" means. The reward is now a share of the rank you are actually on, so it keeps pace with you instead of falling behind. A skill sitting at zero climbs fast; one that is already healthy moves a little. You do not have to think about any of that — it just stops being hopeless.

**The turn-in lockout is down from 20 hours to 1 hour.** These are meant to be enjoyable side skills, not a second job. If you want to spend a weekend pushing Cooking, that is allowed now.

Tasks exist for Alchemy, Cooking, Fletching and all four tinkering skills. Salvaging is unchanged — it already worked.

# Lockpicking

Lockpick had the same problem for a different reason, and it was the worst off of the lot. Picking now pays properly, and above the point where the old rate started falling behind it switches to the same rank-based reward the crafts use.

You do not need to find harder locks. **No lock anywhere got harder to pick** — that would have meant doors you could no longer open, which was never worth it. Harder locks are still worth more than easy ones, so a real chest beats a house door, but nothing was taken away.

# Skills and attributes

**Evading attacks now trains Quickness**, as a secondary gain alongside Coordination. Nothing was removed — this is added on top. It is deliberately a steady trickle rather than a windfall.

**Health no longer waits on Endurance the way it did.** Endurance was the only real route to a bigger health pool and it climbed too slowly to keep up with the content, which made higher tiers gated behind a number nobody could reach. That link is loosened.

**Summoning now trains Endurance**, giving it a second path.

# `@sg-train`

If you have pruned a skill and want it back, `@sg-train <skill>` re-trains it directly. Skill credits were never actually required for this — the client just would not let you click the button when you had none. Your ranks and experience were always preserved; this gives you the way back in.

# Also

A cooking collector in Uziz has been standing in the wrong place since 2022 — it was a duplicate of the Al-Arqas one, sharing its quest, so it could never actually pay you. It is now the collector that was supposed to be there.

Everything above is tunable while the server runs. If any of it feels wrong, say so in #bugs or just tell me — none of these numbers are precious, and several of them are first guesses that will move once we see them in use.
